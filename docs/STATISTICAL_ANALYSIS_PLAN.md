# Statistical Analysis Plan — Template

## Primary estimand

Incremental out-of-sample predictive value of ABO genotype/phenotype beyond prespecified clinical and contextual predictors for one explicitly defined outcome.

## Prespecified sequence

1. Freeze cohort and outcome definitions.
2. Validate ABO calls and genotype–serology concordance.
3. Describe missingness and use an approved imputation strategy.
4. Fit the nested model ladder without test-set tuning.
5. Evaluate discrimination, calibration, Brier score, and decision-curve net benefit.
6. Validate by time, site, geography, ancestry, and relevant pathogen strain.
7. Run negative controls and quantitative bias analyses.
8. Report all prespecified analyses, including null results.

## Multiplicity

Define one primary outcome and one primary ABO contrast. Label all additional outcomes, interactions, pathogen strains, and subgroup analyses secondary or exploratory; control false discovery rate within each declared family.

## Missing data

Do not use complete-case analysis by default. Describe the missingness mechanism, perform multiple imputation inside resampling where appropriate, and compare with prespecified sensitivity analyses.
