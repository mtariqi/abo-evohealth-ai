# Datasheet: Synthetic Demonstration Cohort

- **Origin:** Generated locally; no real people or protected health information.
- **Unit:** One synthetic patient per row.
- **Purpose:** Exercise validation and modeling code.
- **Outcome:** Simulated one-year VTE indicator.
- **Sensitive fields:** `genetic_ancestry` is included only to test stratified evaluation.
- **Known limitation:** Marginal distributions and causal relations are artificial.
- **Redistribution:** Permitted with the repository, but must remain labeled synthetic.
